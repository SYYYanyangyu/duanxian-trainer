# 短线选股台

本地 A 股龙头/打板观察台：拉东方财富涨停池，按东财「所属板块」拆行业和概念，纸上四个角色对打。不接实盘下单。

## 跑起来

1. 安装 Python 3.10+、Node.js 18+
2. 复制 `.env.example` 为 `.env`，填入 `DEEPSEEK_API_KEY`（可选，不填则大模型角色待选股）
3. 双击 `start.bat`，或：

```bat
cd web
npm install
npm run build
cd ..
python server.py
```

打开 http://127.0.0.1:8765/

## 四个角色

每人 **10 万** 纸上资金。`盯` / `打补涨` 成交按每笔 **2 万** 计，次日收盘涨幅结算；`盯不打`、空仓、开盘涨停买不进不占资金。

| 角色 | 思路 |
| --- | --- |
| 纪律派 | 分歧日最多盯不打；情绪好才做最强 |
| 补涨派 | 专打后排，用来对照亏钱方式 |
| 空仓派 | 全天空仓 |
| 大模型 | 按打法思路选股，需 DeepSeek Key |

## 数据

涨停池、炸板、竞价报价来自东方财富公开接口。题材归类用个股 `slist` 所属板块：一级/二级/三级行业只展示，不拿「基础化工」这种大类去假成群。
